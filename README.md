## 市场采购与品质

成长模式比较购买与自给，按价格、收益及省下的时间采购。已取消固定金币底线和每小时采购额度；旧版的这两项数值不再限制购买，仍保留当前项目明确需要的金币并核对实际余额。“按收益采购”可关闭市场购买，补药还有独立开关。修改偏好不会启动暂停中的助手。近一小时承诺额只作记录，不作为消费上限。现有卖货授权和稀有物品保护保持原规则。

- 装备：比较实际属性、可穿条件、赶路及采购筹币时间，买到后完成原换装项目。每个装备位询价评分最高的三个已解锁基础档及当前装备档，覆盖普通至史诗、+0 至 +5。只为有效升级采购，不因颜色更高就换装。
- 材料：制作先用现货，缺口优先比较市场供料；按一批所需数量核对卖盘深度、合计金币和自备时间，缺货、过贵或买不起再自备。报价参与自主发展、经验优先、主业与日常路线估算，买来的原料不虚构采集经验；正在执行原任务时后台预查后续材料。普通配方仍只使用普通材料，便宜的稀有原料不会冒充普通原料。
- 制作：已有背包和仓库材料一起算。练级按经验与供料耗时比较普通至史诗配方，只做现有材料能支持的高品质批次，用完重新选择。装备可沿高品质原料→中间品→成品制作，已有部分同品质材料时也可按收益补齐缺口，与直接买成品比较。按原生规则，煤和野生草药不随品质升级；其它需要同品质的材料不能混用。
- 药水：各品质每瓶仍是一小时，自动使用普通至史诗，药效倍率依次为 1、1.3、1.6、2.2，按价格／药效比较。剩余不超过 6 小时才补，沿用约 20 小时的批量目标与独立补药开关；现货优先，正常存仓期间可续用仓库药水，需买药时保存并恢复原路线，回仓阶段刚结束但仍在仓库旁也可续药。多个适用药效都缺时，先按新鲜报价为其他药效留出一瓶费用，再叠加约 20 小时药效；缺货、金额不足或没有安全回仓机会时不能保证不断药，不在仓库等待；普通至史诗现有盈余不受采购开关限制，无近期报价时使用基础估值；仅饮用当前可取用且不占总库存预留的部分。
- 食物：出战仍优先熟食，按有效回血／价格采购并遵守游戏的自动进食品质上限。普通至史诗增益食物另按本次战斗可用的时长与价格比较；助手普通开战或加入 Boss 前，取消显式指定的传说食物，并把过高的自动进食品质上限降到史诗，分别等服务器确认后才参战；苦根等作物主要用于合算的减伤增益。

所有市场采购发单前重查报价、金币、仓位和订单状态；缺货、过贵或金币不足时继续自给。稀有材料及仍有用途的品质／强化装备继续保留；淘汰装备按当前出售规则处理，目标与配方用料不拿去喝掉或卖掉。辅助模式不因本次更新自动采购；物品目标仍仅支持普通品质。这是有限候选和估算窗口内的规划，不是全市场最优套利。

## 物品目标

展开助手的「物品目标」，选择普通品质物品，填写「另外获得」的数量，再点「开始目标」。例如原有 30 个铁锭，填写 100，需存量达到 130 才完成。启动先同步最新库存；仓库、背包、溢出、已穿戴和本人已有卖单共同计数，搬运、穿脱及撤回挂单不算新增，采购算新增。数量按净增加计算；目标进行中消耗或售出原有同类物品，会相应增加缺口。

折叠后的助手条直接显示目标物品、已新增／目标数量和百分比，暂停后仍可查看。生产目标按剩余缺口集中准备整条材料链，不再每 50 份往返切换；原生满包存仓仍照常进行。已有可用材料先用，烹饪烧焦等实际损耗按剩余成品缺口继续补料，完成后恢复原策略。普通练级也取消固定 50 份限制，按当前计划的供料时间和等级需求安排有用批次，保留已经开始的备料承诺。

可以先输入中文或英文名称筛选目标物品，例如“种子”“钢”“dragonleaf”。无匹配时不能开始目标；清空搜索恢复完整列表和之前选择。搜索、选择和填写数量不会修改正在执行的目标，点击“开始目标”才会应用。

目标期间集中准备材料、解锁必要技能并生产，不被日常或普通成长轮转替换。最终成品按剩余数量分批制作，供料仍按整包／整批推进；多产配方和整批收菜可能略超出所填数量。缺少来源、技能条件或仓位时显示原因并保留目标，不擅自改目标。满仓整理仍受原出售授权和物资保护约束。

目标进行期间保护目标物品和原料；种子目标暂停自动播种，食物目标存在被 Boss 自动补给消耗的风险时暂缓新一轮参战。其他作物在任务边界使用现有种子收种，不额外为无关农事采购或采种。目标完成后存仓，再继续原成长策略；原先是辅助模式则恢复监看，不代建玩家路线。既有玩家队列、搁置任务和未确认操作不会被接管，处理完后再开始目标。

暂停保留目标和起始库存；同一标签页刷新、同角色断线恢复继续该目标。取消目标后按原策略继续；切换成长策略、主业或战斗职业会取消目标。首版提供已核实来源的普通物品，不指定稀有度或强化等级。

## 种植设置

「照料田地」会持续占用当前工作路线，每 60 秒浇水一次，每次缩短 12 秒 ×（1＋锄头加成），没有上限；游戏 1.0.1202 起在城镇农场一次能浇多块地（锄头普通 1、优秀 2、稀有 3、史诗 4、传说全部 6 块），成熟的城镇田会自动收获补种。一次性的「收获并补种」不会持续浇水。助手以主业工作期间生长、到任务边界合批收种为主，不自动接管持续照料。

每次收获的作物数（1.0.1202）：2 个，种植 25、50、75、99 级各加 1 个，另加锄头加成作为额外作物（小数部分是多 1 个的概率）；锄头的稀有度幸运也计入收获时种子的稀有度。助手估算供料时间、生长中的田能带来的作物，都按这个数。

在面板的农业区域选择“自动选择”或“指定作物”。自动模式在全田解锁前按现有材料需求和收益安排；60 级全开六块田后，草药按草药学安排：先补当前计划缺口，再按下一个配方（已解锁、经验最高且持有对应怪物掉落）配合现有掉落数量补草药，然后每种已解锁药水草药保底约 50 份（够 50 瓶），其余田按农业经验续种；未被其它作物全面替代的高级食物仍各备 500 份，按同品质回血与增益持续时间比较，当前虚空瓜在 75 级后由余烬辣椒替代。低级食物只按明确计划数量种植，当前计划需求更高则按计划补。库存统计包含仓库、背包和溢出的普通至史诗作物，已存传说作物不充当可消耗的常备库存；配方需求仍按精确品质核对。缺计划材料优先，其次补相对库存缺口；计入在田作物；库存都充足时农田也不空闲：在任务结束、返仓或空闲时收获并用现有种子续种（成熟作物自带种子，优先农业经验最高的），不为此采购或采种。手动指定及物品目标继续按玩家选择执行；手动模式只补所选作物，不铲除在长的菜，部分成熟仍等整批收。缺少指定种子时说明原因，按当前模式允许的采购或有时限采种规则准备，不擅自换种；辅助模式仅用现有或收回的种子。选择在本浏览器保存，改变选项不会立即发送操作或启动暂停中的助手。

新面板把当前状态和开始／暂停放在前面，农业、Boss 与折叠设置分开，长说明和故障记录在详情中查看；窄屏按可用宽度排版。

缩小后按住“助手／运行状态”区域即可拖动，支持鼠标和触屏，位置在本机保存。刷新后再次缩小会回到保存位置；展开面板或调整窗口大小时自动保持可见，开始、暂停与展开按钮仍可正常点击。

## 农田与房屋发展

农田按农业等级自动解锁：初始两块，15／30／45／60 级各增加一块。所有已解锁田地都纳入收种，缺少种子按原有采购／自采规则补齐；持续种收推进农业，面板显示下一块田的门槛。

三个成长模式会逐块购买房屋周围的可扩建地块：核对当前金币和当前计划必要开销，每次只开一块，前一块施工完成后再开下一块，费用随已拥有地块递增。设施优先当前工作和仓库压力，在空房间摆放；同一趟回家还会检查其他已摆放、属于会用到职业的设施。一个设施在升级，不妨碍给另一个投料并启动升级，各自计时。已有足够点数时升级，否则把当前计划、口粮、周转材料之外的普通仓库盈余转换成点数；每次只补一次升级缺口，确认到账后再操作下一项。永久设施按七天有效挂机、分摊各职业使用时间估算收益；这是估算窗口，不承诺七个自然日回本。缺材料或不合算时，在房屋详情显示缺口和暂缓原因。不会为了凑房屋点数打断当前工作去刷材料，也不会把自然成熟等待算成花园加速收益。

房屋操作需要人在家园内。助手等采集一趟已存仓或当前工作结束后，经传送门返家，收到服务器位置确认后才开始建造；离家后恢复原工作地点、品质与剩余数量。扩建和升级计时期间继续原任务。不会挪动或拆除玩家现有设施，不消耗宝石加速，不转换坐骑、宠物、稀有或特殊掉落。物品目标和只收菜＋Boss 辅助模式不额外建房。每次消费等待服务器状态确认；同步后仍无法确认则暂停，避免重复消费。详情在「任务、装备与物资 → 房屋扩建与升级」。

## 指定具体工作

在“成长设置”选择“主业经营”，生活主业的“具体工作”可自动选择，也可固定当前技能下的任意项目：矿石、鱼、树木、偷窃目标，或烹饪、锻造、制箭、炼药、制作配方。战斗主业可选择自动选怪或固定目标怪物，适用于法师、单手／双手战士、短弓／长弓游侠。煤矿和枫树只是例子。

固定项目不会因其它配方经验高、市场行情变化或日常任务而被替换；必要的装备升级和供料仍会进行，收菜、Boss 结束后继续所选工作。缺少条件时显示原因，仓库受阻时也不会擅自换成偷窃。指定怪物仍保留原有武器、生命、食物与持续击杀安全检查，条件不足时不强行开战。

未达到等级的生活项目显示解锁门槛，不能选取。更换具体工作或目标怪物会暂停调度，游戏现有任务继续，点击“开始”后在任务边界应用。更换主业时具体工作重置为自动；其它成长模式不使用这一限制。选择保存在当前浏览器，刷新后恢复。

## 选择成长策略

| 模式 | 安排方式 | 适合的目标 |
| --- | --- | --- |
| 自主发展（默认） | 结合供料、已有材料、有效解锁和收入，完成一个发展计划再决策；长期补齐生活与所选主攻击技能 | 先集中发展，再逐步全能 |
| 经验优先 | 比较包含供料和往返的总经验效率，允许等级差距拉大 | 累计经验更多 |
| 主业经营 | 由你指定一个主业，或选择“自动选择（按收益）”；脚本安排本业配方、供料和工具 | 专精指定技能或以收入支撑成长 |
| 只收菜＋蹭世界 Boss | 只处理合批收菜、现有种子补种和世界 Boss，临时外出后继续玩家原队列 | 自己安排练级与生产，脚本提供辅助 |

战斗职业只决定需要战斗时使用的路线，主业可以是生活技能。切换策略会暂停脚本调度，已有游戏任务继续；点击“开始”后按新策略调度。常规成长切换仍遵守满包和制作批次边界，收菜等已种田地全部成熟。偏好保存在当前浏览器；运行中的同一标签页刷新或重连恢复原模式，旧“均衡成长”在本次更新后对应“自主发展”，其余已选模式不变。

“只收菜＋蹭世界 Boss”允许玩家保留并编辑自己的任务队列。此模式不安排练级、打造换装、强化、日常任务、交易或采购；按实际任务续喝可取用的普通至史诗盈余药水，玩家队列与 Boss 临时操作优先；农业只使用已有或收回的种子补种，不采种或解锁新作物。切换其它模式后才恢复相应的成长规划。

四种模式均会留意服务器公布的世界 Boss；来得及赶到时，用当前装备临时参战。在「世界 Boss → 参战方式」选择「全程打到结束」（默认）或「确认有效伤害后离开」。离开模式须收到服务器确认的本人正伤害回报，走到旁边、点击加入、零伤害或重新连接均不算；退出后恢复原任务，本轮不再自动返回。按游戏说明，命中过即可参与分配，金币随贡献变化；实际奖励以本轮结束后的掉落记录为准。选择在本浏览器保存，修改选项不会启动暂停中的助手，也不干预玩家手动加入的战斗。收菜通过游戏原生临时任务保存当前工作，Boss 出行则暂存当前任务的剩余份额并保留队列顺序，结束后继续原任务。角色需要实际赶路，原任务在这段时间暂停生产；不会清空或重建玩家队列。手动操作始终优先；Boss 赶路卡住、已结束或已阵亡时不反复返场，不购买补给或捐赠物资。

选择“主业经营”后会出现“主业”下拉框：可选采矿、钓鱼、伐木、盗窃、烹饪、锻造、箭术制作、炼药、制作，以及按所选战斗职业进行的战斗。农业继续后台合批种收，强化随有用装备升级，因此不单列为前台主业。手选采矿后，即使盗窃等级更高、赚钱更多或暂时没有市场报价，也不会擅自改成盗窃；需要材料、工具或等待农作物时，可安排必要辅助工作。更换正在运行的主业会暂停调度，点击“开始”应用；切换其它策略仍保留主业偏好。

“自动选择（按收益）”保留按行情选择主业的方式，也是旧版偏好的默认值。关闭自动出售时不把库存销售算成收入，自动选择优先比较直接金币，手选制造仍按本业经验与供料时间安排。开启出售后，主业经营采用保守估算：原料按可持续获取成本计算，普通产出只按新鲜买单、税后价格和有限需求评估，保留计划材料及库存保护。自动选择没有可靠行情时先做直接产金币的任务；手选主业只在本技能内比较有报价支持的收益，没有可靠行情时按本业经验与供料时间安排路线，不把未知售价或未成交库存算成收入。供料和市场成交仍可能使实际收益偏离估算；它不是全市场实时最优套利，也不会为追平无关技能而轮训。

## 自主发展如何安排

不要求每个技能同时同级。先选择值得投入的解锁或等级里程碑，准备相关工具、整批材料和所需金币，再把本计划做完。已有材料按节省的供料时间计入；可重复赚钱则计算原料补充成本、税后买单与有限需求，不把未成交货物当金币。没有可靠行情时仍可自给或赚直接金币。

每四个发展计划补一次长期未发展的能力，避免单一赚钱路线永久霸占调度。等待作物等条件时使用现有装备做可行工作，不另外开启一整条工具升级链；原条件恢复后在安全边界返回。日常仍优先且完成后返回发展计划，Boss、物品目标保留原规则。运行中的同页刷新和后台 Worker 重建会保留计划及完成记录。面板的下一方向只是候选，完成本计划后会按新库存和行情重评。

普通出售仍沿用玩家开关，满仓清理遵守资产保护；全部占位物品均受保护或等待成交时，显示原因并临时做不新增种类的工作，不删除贵重物品来保证表面上的“连续练级”。这是有限候选的估算规划，不保证任何行情下最优或盈利。

内置公开客户端数据已核对到 `index-B2257EY9.js`（2026-10-13）：211 个有效工作／配方；不再规划公开表中已淘汰的 10 个配方，既有物品仍可识别，并同步当前装备属性与穿戴等级。

## 后台规划与等待处理

成长选择、材料链、装备和市场方案的计算在本机 Web Worker 内完成，公开客户端的静态数据解析也放到后台。游戏连接、操作确认和 Boss 参战恢复仍在页面处理。计算期间原生任务继续，助手只在既有任务边界切换；不会为思考下一步先停工。

装备和熟食首次询价最多等待 4 秒，报价未齐也先继续供料／练级；过期材料报价后台刷新，不重新卡住任务。后台方案提交前重新核对角色、队列、库存、设置、报价和未确认操作；状态已变化就丢弃旧方案。单次 Worker 计算超过 8 秒会终止线程，重试仍失败则明确提示并暂停调度，已有游戏任务继续。浏览器不提供 Worker 时显示兼容计算模式。

采矿、伐木在自主发展／经验优先练级时，可原地清理不需要的普通主产物；只有省下的往返时间超过产物价值才执行。钓鱼、偷窃不自动丢。保留至少 50 件周转物资及所有计划材料、稀有物、副产物，不启用原生全品质丢弃。保留物占满背包时仍需正常存仓。

两个游戏域名的浏览器存储彼此独立。首次切换到新域名时，助手默认暂停，请核对模式并点击开始；不会读取另一站点的登录信息或自动搬运设置。熟食目标仍受保护：参战前换用非目标食物，只有没有替代食物时才跳过本场 Boss，并在日志和当前原因中说明。

  - **修复“后台规划连续失败：本次规划耗时过长”而暂停**：物品多的仓库里，出售判断把每件物品和其他所有物品逐一比较，金币效率表又为每个候选工作重复做十来次，一次规划要 3 秒以上（大仓库模拟约 24 秒）。现在同款比较只做一次，金币效率表只判断该工作的产物，同样的模拟约 1 秒以内，判断结果不变。耗时过长时，提示会写出最慢的几步（诊断里的规划记录也有各步耗时）。实测后又修两处：① 后台每次计算先按“魔法”算了一遍金币效率表，规划时再按你的战斗职业重算，两张表互相挤掉缓存，任务边界每次都要约 1.6 秒；现在先设好职业，并保留最近两张表，一分钟内只算一次。② 估算制作材料时每一步都复制整个仓库，改为只记录改动。
  - **修复现金预算越滚越大（实测 1,024,020,000）**：计划为值得的强化预留金币时，每次整理库存（几秒一次）都在“已含强化金币的预算”上再加一次强化金币，预算无限增长，计划于是一直去赚钱。现在预算里记下强化占多少，只加一次；旧版本存下的虚高预算在载入时恢复为只含强化金币。
  - **装备只有一个执行步骤**：以前按投资表办事的有好几处，各管一部分——换上已持有的装备只看当前技能的位置，市场购买只在当前目标技能的升级步骤里做，空闲填充和任务另有“市场最好的一行”规则，锄头又单独一步——所以表上写“值得，可做”的项可能一直没人做。现在每个任务边界（自己的练级、为别的目标供料、同一工作继续、战斗、任务、空闲填充）都走同一个装备步骤，覆盖所有位置：先换上投资表里“已持有”的更好装备，再买每个位置首选为“市场”的那一行（等几秒实时报价）。强化仍由整理步骤按同一张表做。
  - **规划慢不再暂停助手**：以前一次规划超过 3 秒就当作出错，连续两次就暂停调度（游戏原任务继续，但助手停下，之后连接一断就一直停着）。现在慢的结果照常使用，只要计算期间状态没变（原有的状态核对）；超过 8 秒的计算仍会被终止。诊断里的规划记录会标“较慢”，并写出最慢的几步：计划、整理、房屋、药水食物、选目标、任务、收菜、投资表、候选等各自的耗时。另外出售判断只在需要时才建装备比较，金币效率表每个候选只算一次保留量，装备属性只算一次，大仓库下这几步约快 25%。
  - **断线提示不再误导**：运行中断线时，游戏 1 秒左右自动重连，同一角色登录后助手自动继续（刷新同一标签页、游戏自己为新版本刷新页面也一样）。没在运行时断线，以前会显示“连接已断开，调度保持暂停”，像是断线把它停了；现在不改提示，面板继续写它原本为什么没在运行。打开页面时读取已保存的职业也不再记成“已选择××，点击开始重新规划”。重连时同一次断线也不再记两条。
  - **账号没验证邮箱时不再暂停**：游戏现在要求账号有验证过的邮箱才能用市场、交易和公会仓库。以前市场下单被拒（`email-needed`）就当作错误暂停调度，之后刷新页面也不会自己恢复（刷新只恢复正在运行的调度）。现在这和铁人角色走同一条规则：市场对这个角色关闭，不再挂单买卖、不按市场价规划买入或估值，按自给和商人回收继续；这个状态按角色保存，刷新后仍记得，6 小时后试一次，游戏报告邮箱已验证就立即恢复。刷新后恢复调度时，先恢复运行状态，再逐项恢复其余保存的计划，某一项读不出来只会重新规划那一项，不会让整个调度丢失。
  - **可以强化传说装备**：身上穿着的传说装备和其他品质一样进投资表，按同一个回本规则决定强化到 +几，并照表执行（强化失败只降级、不会毁掉装备，花费按失败回到 +0 估算）。其他传说规则不变：传说物品不卖、不吃不喝、不当材料、不丢弃。
  - **出售攒成一批再卖**：以前每次回仓都停下当前路线卖一次，而且只卖给最高价的第一张买单，交易记录里同一物品一行行几十几百件。现在一次出售吃掉同一最高价上的所有买单；同一物品 30 分钟内只卖一次（和挂单复核同一节奏），其间产出攒着下次一起卖，路线也不再每趟被打断。仓库满时照旧立即出售。
  - **出售价格按当日均价，一条规则**：去掉“挂单／直接卖给买单”开关。每件物品按当日成交均价决定：买单接近均价（5% 以内）就直接卖，比如熟龙虾买单 390、7 天均价 359；均价明显高于买单就按均价挂单，比如稀有 Tin 买单 2,550、均价 4,630。收益估值走同一规则。
  - **强化只看投资表，停点最高 +20**：去掉旧的“同装备每阶段最多五次、失败一次就停到下一阶段”规则。投资表的期望花费本来就算进了失败回到 +0 再重来，那条规则和它冲突：陨铁锄失败一次后要等农业 95 级才再试，表上却一直显示“值得，可做”。现在失败后由投资表重新判断要不要再试；只保留“上一次结果未确认时不重复发送”。停点从 +5 扩到游戏上限 +20，按同一回本规则（省下 ≥ 花费 1.2 倍）选净省最多的一级；最高级装备没有下一档，使用期按 30 天算。
  - **市场上的强化件也到 +20**：投资表给市场上已强化的装备定价、采购步骤买入，都从 +5 扩到 +20。在用装备也比较“同品质、更高 +N”的市场现货（以前只看更高品质），和自己强化按同一规则比谁更省。价格总表里没有挂单的版本不再单独查询，避免查询量翻倍。
  - **强化不再等批次结束**：游戏的强化在后台进行，不停路线、不需要在仓库，所以投资表里值得做、钱够的强化现在立即开始。以前要等当前烹饪等批次结束，而那时往往先去卖东西，接着又开始下一批，强化一直轮不到。
  - **所有花费都过同一个回本门槛**：省下的时间至少是花费的 1.2 倍才做，花费里持有的东西按售价算。以前有几处各有规则：房屋地块只要钱够就买（现在只在某个设施没有空地、且它第一级连地块价格都回本时才买）；增益食物收益大于卖价就买或吃、自己的食物也按卖价算、饱食按固定 10% 省时（现在自己的按售价、买的按卖价，饱食按它让战斗实际变快多少）；用作物减伤、原地丢弃盈余没有 1.2 倍门槛（盈余也改按售价估值）；金币药水和滋补药水没有价值估算、只能按基础价 3 倍封顶（现在按多得的击杀金币、省下的食物算）；稀有药水要卖价达到同等药效最低价的 2 倍才卖（现在按“卖还是自己用”：卖价高于用便宜药水替代同等药效的花费就卖）。
  - **金币下限、鼠尾草种子、副产物来源，各只有一个规则**：① 经验优先的金币下限按金币效率表的价格筛选，与计划页金币列和下限按钮一致；金币表里没有的工作在金币列里算 0（以前显示未扣成本的直接金币）。② 鼠尾草种子可以向商人买，共用的原料成本现在也知道这一点（以前按稀有副产物定价）。③ 副产物（例如种子、宝石）从哪个工作获取，补料、路线估算、原料成本、农田采种都按同一个“每个副产物最快”的来源；没有已解锁来源时就是暂时得不到（以前按每个 3600 秒的假设定价）。
  - **主业收入按金币效率表**：主业（自动）以前用另一套“可持续”的估算排收入，发展计划的收入加成又是第三套，与计划页金币表、金币效率不一定一致。现在主业直接按金币效率表的行选工作、写出预计金币，发展计划的收入加成也读同一张表（表里已把用掉的库存按售价扣掉，所以不会把库存当成白来的收入）。
  - **战斗只有一种评估**：以前打哪个怪物有三套算法（实际战斗时按未校准的公式和总经验；选目标时按校准后的路线估算；投资表按主技能经验），食物的价钱也有三种算法，部分战斗路径还按属性分数挑武器。现在只有一个：每次击杀连同吃的食物、补给往返和来回路程，按你的实测效率校准（比较装备时两边仍按公式），选目标、实际战斗、投资表都用它；食物按共用的原料成本定价（买或自制并扣经验）；武器一律按装备效率选。
  - **买还是自己做，只有一个判断**：以前评分配方时按一套规则假定“这个原料买”，真正下单时又是另一套（自制只要不贵过 15% 就不买、采购超过半小时金币就不买、拿不扣经验的自给时间比……），还有的地方根本不比较；结果评分时算作买的原料，下单时被拒。现在所有买的步骤（市场补料、阶段备料、路线估算、买熟食、药水自制还是买）都用同一个判断：价格折成金币效率的时间加一趟仓库，对比自制或自采的时间扣掉所练技能获得的经验；按实时卖价比较，便宜的那个赢，没有偏向，也没有时间上限。原料由哪个工作来做也只按这个规则选；怪物掉落按实际打怪（含吃的）每个掉落的时间算，不再一律按 60 秒。
  - **选目标和干活用同一个配方评分**：以前选目标（发展计划、经验优先、主业）用一套“模拟一段路线”的经验速度，真正干活时再用另一套评分选配方，所以选目标时看好的配方，开工后可能换掉，发展计划显示的预计时间也和实际不同。现在两边用同一套评分：发展计划按整阶段（含采集原料）的经验速度为每个技能选配方、估算时间，开工的阶段就用这个配方；经验优先和主业按同一个批次评分选择。高品质配方是否值得用也随之一致。
  - **卖装备、种什么、留多少钱，各只有一个规则**：① 出售清单判断同款装备留哪件，以前看品质等级和属性，换装却看效率，可能把会换上的那件挂出去卖；现在本职业的装备按同一个效率比较（其他职业的仍按属性）。② 收菜、辅助模式收菜、锄头估值各有一套选作物的顺序，现在都按同一个顺序（辅助模式只在有种子的作物里选）；农田状态说的采种地点就是实际去的地点。③ 保留的金币以前各算各的（有的加总、有的取最大、市场购买只看当前目标），现在买东西、扩建房屋、整理库存都留同样的金币：当前目标各计划中最多的那份，加上待做装备项目的那份。
  - **只有一张投资表**：投资表以前随“当前目标”变：计划页、整理时的装备步骤、筹资各拿不同的目标去算，工具对应哪个工作、和哪个怪物比，结果可能不同。现在投资表与目标无关：工具按你实际做得最多的那个工作评估（实测），没有实测时按正在做的工作、再按最好的工作；战斗按你实际打得最多、且现在能安全打的怪物。各项工作的时间占比也是实测；没有实测时按各技能累计经验估算。主业模式也会为值得但钱不够的升级筹资（以前只有自主发展和经验优先模式会）。
  - **强化只按投资表**：主业和发展模式以前只强化主业技能的工具（或战斗时只强化战斗装备），而金币预留和筹资却按整张投资表——会为不会去做的强化留钱、筹资。现在三者都按同一张表（表里已按你实际做各项工作的时间算收益）。物资页的“强化建议”改为直接列出投资表的强化行：停点、含失败的期望花费、省下的时间和结论，与实际执行一致；说明里的“目标 +5”改为投资表的停点。
  - **只有一个换任务门槛**：练级阶段换配方（放弃正在准备的配方、放弃保存的配方）以前要好 1.5 倍，换高品质配方则不需要门槛；现在都用同一个 10% 门槛（与换任务相同）。另删去了市场里两套旧的采购规则（只在没有配置采购时才会用到）。
  - **计划装备也按投资表**：以前“计划装备”是另一套选法（有材料就规划最高品质、低于制作等级也规划），自己在练级前先打造（“先打造计划装备”），并为当前和下一档装备保留高品质材料。现在计划装备＝投资表各位置的“自制”首选，只由同一个装备项目步骤制作（几件共用的高品质锭仍一次备齐），只为这些装备保留材料；还做不了的装备不再预留，材料按“卖还是自己用”的同一规则处理。物资页“装备”显示的“当前可穿”就是投资表首选（怎么得到、花多少、省多少），“下一档”只作参考、不留材料。供料前另外“准备供料工具”的一步也去掉了，由同一个装备步骤覆盖。
  - **装备只在你用到的时间里省时间**：投资表以前把每件工具都当作全天在用，不挖矿的角色也会被算出“镐值得升级”。现在省下的时间按账号实际花在该项工作上的时间比例（与精通选择用的同一份实测时间）计算：使用期＝到下一档或 30 天内、你实际在做这项工作的时间。没有实测时，当前目标的工作算全部、其他算 0；锄头照常按全部（田一直在长）。空着的位置也会评估（以前只看已穿戴的位置）。已持有的更好装备仍总是首选（免费）。
  - **装备项目（自制）也按投资表**：投资表里“自制”的花费改用共用的原料成本——制作本身和取得原料的时间（库存原料按售价、买的按价格折成时间），扣掉制作在所练技能里获得的经验（按该技能最好的经验速度折成时间），再加上路线上的往返（去矿、熔炉、铁砧）。某个位置的首选是“自制”时，才开装备项目做那一件（按净省时最多，而不是最便宜的一件或属性最高的一件）；进行中的项目只要它那一行仍然回本就继续，不回本就放弃。以前阶段装备按“效率最高”另选、不看回本，且只看当前技能的位置。
  - **锄头纳入投资表、换装、市场购买和强化**：锄头的价值按田地多收的作物算——每块地（种着的作物，空地按下一季会种的作物）每次收获多出的作物 × 售价 ÷ 生长时间，得到每秒多赚的金币；使用期按田地的种植经验算到下一档锄头为止（最多 30 天）。多赚的金币超过价格 1.2 倍才值得（价格和收益都是金币，与金币效率无关）。无论在练什么（包括为别的目标采集供料、同一工作继续进行时），任务边界都会换上已持有更好的锄头、买投资表选中的锄头：先看当前目标自己的装备，再看锄头，并像其他购买一样在边界等几秒实时报价（第一版不等报价，到下一个边界报价已过期，所以表上写“值得，可做”却一直没买；供料工作也完全不看锄头）。强化建议也会选锄头。没装锄头时也会推荐买一把。计划页的投资表除了所有“值得”的项，每个位置至少列出前三个选择（以前只显示前 8 行，不值得的锄头选项看起来像没考虑过）。
  - **跟进游戏 1.0.1202 的种植改动**：每次收获的作物数改为游戏的新规则（2 个，种植 25/50/75/99 级各加 1，另加锄头加成），以前按“4＋等级/100”估算；生长中的田按确定能收到的整数作物计入库存；照料缩短的时间不再按一半封顶；物资页的强化建议里，锄头显示为“每次收获多几个作物”，不再写“强化锄头没有用”。
  - **赚金币只有一种做法：金币效率表的第一行**：以前另有一份“直接给金币的摊位”清单（goldJobs），缺计划现金时总去那里（例如宝石摊）、主业等待条件时临时去偷窃摊位，金币效率表正在计算时也按它折算。现在这份清单已删除：缺现金、筹资、主业等待时都做金币效率表第一行的工作（例如挖矿卖矿），缺钱期间自动出售它的产物，够了就停；表计算中按上一张表的效率折算（第一次先不买原料算一遍，再按得出的效率重算）；仓库满且全部受保护时，仍只做不产生新物品种类的纯金币工作，但按金币效率表的顺序选；经验优先的目标说明里的金币也是表上的数（含出售产物）。
  - **练级阶段要用的材料一律不卖**：阶段计入的材料（例如锻造到 85 级要的钴锭、钴矿和煤，普通品质也一样）全部保留，只卖超出阶段需要的部分。高品质材料只有“自用值得”（为阶段省下的时间高于售价）时才计入阶段，计入的就保留，不计入的才卖；阶段次数、保留量、选配方和出售都用同一个判断。
  - **金币效率就是计划页“全部技能按金币/时比较”的第一行**：同一张表既显示给你，也是助手折算金币与时间用的数（以前另算，只看偷窃约 17 金币/秒，和表上相差上百倍）。表里包括卖出产物的收入：普通产物按买单能吃下的量，高品质矿石也会卖（传说的不卖，计划装备与药水要用的保留）。用持有的高品质材料做的批次标为“库存批次，一次性”，不作为效率；作为效率的一行标“金币效率”。**库存材料不再当作免费**：工作用掉的库存材料（高品质的、普通的，连战斗吃的食物）按它本来能卖的价钱（扣税）计入成本，所以库存批次显示的是“成品价减材料价”的净收益；材料比成品还值钱时，这一行就不出现（直接卖材料更好）。买的原料照旧扣金币，自己采集的照旧算时间。
  - **修复战斗时“后台规划连续失败……could not be cloned”而暂停**：共享组件整理（三·上）里食物回血的计算结果带了一个函数，战斗补给的结果从后台传回页面时无法复制，助手因此暂停并改做备用采集。现在只传数字。
  - **每日任务不再等装备项目**：每日任务以前也按“阶段装备”打造装备，例如钓龙虾的每日先要做史诗钴鱼竿，缺史诗钴就一直等，最后每日被搁置。现在任务只换上已有的更好装备、买市场上值得的装备，不开打造项目。
  - **阶段备料计入中间产物的经验**：阶段要做多少次，以前只按最终产品的经验算；锻造钴护胫时，熔炼它的 4 根钴锭同样给锻造经验（480＋4×108），于是备料多出将近一倍（例如 77→85 级备 9,800 副护胫、近 4 万根钴锭，要多挖约 5 万多块煤）。现在同一技能链上还需自己做的步骤都计入经验；已有的库存不重复计。
  - **每日任务不再被长阶段备料挡住**：以前正在为一个阶段备料（例如锻造到 85 级要先备 39,404 根钴锭，要做好几天）或做装备项目时，完全不看任务，每日任务一个都没做。现在每日任务在任务边界照样插进来；原来的阶段先挂起，已备的材料继续保留，每日做完后带着原来的备料进度恢复。每周任务仍等阶段告一段落再做。
  - **临时工作也会买值得的装备；投资表比较所有品质**：等作物成熟时临时去偷窃等“先练其他技能”的工作，以前完全不看装备，连在市场上一趟就能买到、明显值得的工具也不买（例如稀有 Bone gloves 偷窃快约 13%）。现在临时工作仍不做打造装备之类的项目，但市场上值得买的会买，买到后在下一个任务边界换上。投资表以前每件装备只看“刚好比现在好的最低品质”（普通 Bone gloves 只快约 1%），现在各品质都算，取净省时间最多的。
  - **换任务统一要好 10% 以上**：当前任务只有在另一项按同样的平均效率明显更好（超过 10%）时才换。以前各处标准不一（5%、10%、约 11%、20%），升级后配方更是直接换成当时得分最高的那个，估算稍有波动就来回切换。阶段备料仍要好 1.5 倍才换（已采的材料不浪费）；主业经营仍至少做满 30 分钟。
  - **任务效率按天平均**：每个任务记住“实际效率 ÷ 公式效率”，来自实测和引擎模拟，按观察时间加权、半衰期约 1 天，刷新页面后仍保留。以前实测只在完全相同的等级、装备和药水状态下才用，升一级、换件装备或药水到期就退回公式，同一任务一会儿好一会儿差，任务因此来回切换；现在只按公式随等级与装备变化，再乘以这几天的平均效率，后台与页面计算看到的也是同一个数。计划表的来源列会显示“平均”。
  - **后台规划不再因报价刷新作废**：以前市场报价每隔几秒刷新一次，后台算好的计划就有一半被丢弃，连续 3 次后改在页面内用另一套数据重算，两边结果不同，任务来回切换。现在只有挂单、待确认的交易、冷却与设置变化才作废；采用后台结果时保留计算期间页面新收到的报价，已回应的查询不再重复发送。
  - **市场价格历史**：每 5 分钟的价格表（最低卖价、最高买价）和查询到的实时成交，按物品保存近 7 天（最近一天每 3 小时一格，之前按天），存在本浏览器（`deepvein-market-history-v1`，最多 400 种、约数百 KB）。估算产出的出售价值时，若当前买价或挂售价比近 7 天与近一天均价都高出 20% 以上，视为一时的高价，按均价的 1.2 倍计；仍扣市场税、不低于商人收购价，真正出售时照常按实际买单成交。近两小时没有成交时，挂售数量不再一次挂 100，而是不超过观察到的日均成交量（需已观察满一天）。成交量只来自助手查询过的盘口，是下限而非全市场总量。控制台 `deepveinDebug().marketHistory` 可查看。传说物品与原料仍不自动出售。
  - **共享组件整理（一）基础**：等级与经验表、测量记录的键、物品 id／名称／品质、各品质出现概率、决策结果的格式，都只保留一份定义（`levels.js`、`keys.js`、`items.js`、`quality.js`、`result.js`），各功能不再各写一份。顺带修正：满级时“还差多少经验”不再算出 NaN；补药时估算赶路占比用的测量记录带上品质（以前稀有配方读到普通配方的记录）；模拟引擎识别当前任务的方式与规划一致。
  - **共享组件整理（二）金币与价格**：金币效率只有一个来源——已解锁、不耗原料的赚金工作中校准后最快的那个；“赚金币”回退、缺金币时打工、筹资都做这一个工作，金币折算时间、回本判断、药水最高价都按它（`gold.js`）。市场报价只有一个“当前最低卖价”（一分钟内的实时报价，否则用价格表），买入价统一以金币计。物品的出售价值统一扣除市场税，查不到报价时按商人收购价。行为变化：① 背包盈余原地丢弃前，估值改为扣税后的价格。② 顺路去仓库卖货是否值得，按金币效率折算绕路时间（以前按当前任务的金币效率，练级时几乎为 0）。③ 用作物换减伤的估值按出售价值，不再按物品基础价值。④ 筹资时做金币最高的工作，与回本计算用的金币效率一致（以前可能去做卖货收入更高的工作）。
  - **共享组件整理（三·上）效率与战斗**：任务效率、战斗属性、能否安全战斗、药水增益下的击杀时间、每口食物回血都只有一份公式（`rates.js`、`estimates.js`、`supplies.js`）。顺带修正：自制药水估时算上研钵加成；任务估时算上工具与快手；战斗选怪、掉落估值算上护符幸运；“按需采购”的经验损失按校准后的效率；市场挂单、出售提示里的物品名（上一步整理时误改，名称会显示错误）。
  - **共享组件整理（三·中）装备**：装备位置、是否适合本职业、双手武器不带盾、“到下一档前能用多久”都只有一份规则（`gear.js`）；使用期统一为同位置、同风格、同需求的下一档，最多 30 天。行为变化：① 装备升级的收益前后两边都按游戏公式计算（以前战斗装备和自制工具一边用实测、一边用公式，实测里带着药水与房屋加成，会低估升级）。② 坐骑加成按坐骑自己的品质／强化倍率，与走路速度的计算一致。③ 房屋升级的回本期由一周改为 30 天，与装备一致；投资表说明里的“最多一周”改为“最多 30 天”。④ 投资表里按防御等级穿戴的装备，使用期不再用主战斗技能的经验速度去估算防御升级（改为 30 天上限）。
  - **共享组件整理（三·下）原料成本**：“这份原料花多少时间”只有一个算法（`input-cost.js`），选配方、买还是自己做、自制药水与否、阶段备料都用它：库存按出售价值折算时间（但不高于重新获得它的代价，原料本来就不卖）；购买＝价格折时间＋一趟仓库；采集或制作＝所花时间，减去职业所练技能得到的经验（按该技能最快的练法折算为时间）；制作的原料递归同样计算。选配方按（制作经验＋原料采集经验）÷（制作时间＋取得原料时间）。任务与物品目标不计经验抵扣，求快、便宜就买。行为变化：① 选配方时会计入采集原料得到的经验，例如烹饪阶段同时考虑钓鱼经验。② 买成品还是自己做，以前只比较“买原料来做”，现在也比较自己采集；经验抵扣按职业所练的所有技能，不再只看当前目标技能。
  - **共享组件整理（四）库存、保留与仓库往返**：数量只有几种明确的定义（`items.js`）：“可用”＝仓库＋背包（溢出存储不能取出，不算）；“已拥有”＝含溢出、已穿戴和挂单；“手边”＝背包，在仓库旁再加仓库。周转库存 50、战斗食物保留（50 或三趟的携带量）、作物保留 500、玩家锁定的装备、多个计划合并后的保留量、“玩家自己的队列优先”、可吃的食物，都只写一处（`inventory.js`、`supplies.js`、`farming.js`）。仓库往返时间统一一个算法：去家仓库（没有则最近的仓库）入口再回来，按坐骑后的步速。行为变化：① 买原料、顺路卖货、取装备的往返时间计入坐骑加速，且按家仓库计算。② 估算一批路线的背包容量时，稀有原料也按可堆叠计算（以前被当成不可堆叠）。③ 制作估算会保留正在强化的物品的其他强化等级（与库存整理一致）。
  - **自己的挂单不再挡住采购**：助手最多同时保留 3 个自己的出售挂单，以免长期占满挂单槽；以前这个上限也套在购买上，3 个出售挂单在架时就什么都不买（装备、药水原料）。按最低卖价购买会立即成交、不占挂单槽，现在只要游戏的挂单槽未满就可以买。
  - **卡住的“交易待确认”会自动解除**：助手发出市场操作后会等确认，期间不做任何新交易以防重复。若这笔操作游戏根本没执行（例如物品随后被转换成房屋点数），以前会一直等下去，所有采购（装备、药水）都被挡住。现在 10 分钟后若刷新的挂单列表里没有对应挂单、也没有成交（买单也没收到货），就解除等待、恢复比价。
  - **阶段备料会换成明显更好的配方**：“采集够整个阶段再一起制作”的配方以前只看 20 次、把库存当免费，于是仓库里有两千只虾时选了煮虾，而且一旦开始备料就一直不换（烹饪到 60 级解锁龙虾后仍在为 65 级钓四万只虾）。现在按整个阶段（含仍需采集的原料）比较每分钟经验；已在备料的阶段、或已保存的配方，若另一配方至少好 1.5 倍就换过去，已采到的原料留在仓库（例如已备够虾、但仓库里有近一万只龙虾时，改煮龙虾）。例如 64 级烹饪到 65：煮龙虾约 4,700 次，代替再钓三万多只虾。
  - **热门技能不再误报“校验不一致”**：游戏按电脑时钟决定当前热门技能，助手却用最后一次收到的游戏状态里的时间；助手暂停时不再请求新状态，这个时间就停在暂停那一刻，过了一个 30 分钟窗口后就与游戏显示不符，于是反复提示“游戏显示 woodcutting，本地计算 fishing”并停用热门跟随。现在按最后状态加上之后经过的时间计算。已核对游戏新客户端（index-Di-5ljk5.js）的轮换规则与本地数据完全一致（30 分钟一档，顺序、稀有技能、种子均未变）。
  - **后台也不显示“离开”**：游戏在标签页隐藏 60 秒后会通知服务器你已离开（并隐藏其他玩家），回来时弹出“离线期间”汇总。现在游戏看到的标签页始终可见（document.hidden 恒为 false，切换事件不传给游戏），所以不会被标记为离开，也不再弹出这个汇总；助手自己仍按真实状态判断（例如游戏自己的 Boss 加入流程只在真正可见时才交给游戏）。浏览器在后台仍会暂停游戏画面刷新，这不影响服务器上的角色和助手的调度。控制台 `deepveinAwake()` 中 gameSeesVisible 为 true 即生效。
  - **后台标签页保持运行**：Chrome 会把后台标签页的定时器降到约每分钟一次，还可能冻结页面，于是助手几分钟收不到新状态、进入“重新同步”。现在由一个 Worker 每秒唤醒页面（Worker 的定时器不受这种降频），并持有一把 Web Lock 让 Chrome 不冻结页面；控制台 `deepveinAwake()` 可查看。Chrome 的“节省内存”仍可能在内存紧张时丢弃标签页，可在 设置 → 性能 → “始终让这些网站保持活动状态” 里加入 deepveinidle.com。
  - **回家前再确认一次**：前往传送门的途中目标或房屋可能已变化（例如断线重连后重新选了目标、设施已在升级），到门口时若家里已没有要做的事，就取消这次回家并恢复原任务，不再进家门又马上出来。
  - **投资表和装备计划计入已持有的装备**：以前“投资（金币换时间）”只考虑普通到史诗的新装备，仓库里已有的更好装备（例如传说钴盾、罕见钴盾）不计入，于是建议另做一面钴盾。现在每个部位先看仓库和背包里已有、可穿且更好的装备（任何品质，传说也算：穿上仍归你），作为“已持有、0 金币”的选项；不比它好的强化、换品质和换装备不再列出。装备计划的“当前可穿”同样直接用已有的传说装备。实际换装也不再只在练该技能的主目标时才做：任何时候（包括作为填充或临时任务去打怪、采集）只要仓库或背包里有可穿、比身上更好的装备，就先去仓库换上，只花一趟仓库；为别的目标供料（例如为战斗做饭、为制作砍木头）时也会先换上已有的更好工具。花钱买或另做装备仍只在练该技能的主目标时考虑。市场买装备的判断与投资表一致：按这件装备实际会用的时间计算是否划算，即按当前速度练到同部位下一档可穿为止的时间（最短 30 分钟、最长 30 天，已是最高档时按 30 天）；以前按固定 2 小时比较，花约一小时收入的装备永远“不划算”，于是投资表写着“值得，可做”的史诗工具一直没有买。市场买工具时，效果也只按它加快的那个动作计算，换前换后都用游戏公式（与投资表相同；实测速度含药水、房屋等加成，只存在于身上这件工具，拿它对比公式会把提升算没；要自己制作的工具仍按含采集的整体估算）：以前把采集原料的时间也算进去，为大批制作备料时原料被视为“还要去钓”，史诗钴平底锅的 +13.5% 被稀释成 +3.4%，同样从不划算。同一份工作连续进行时（例如整个阶段一直在煮虾），也在每次返仓的任务边界复核工具，不再要等这份工作结束才考虑换平底锅；决定购买后会在这个边界等几秒拿到实时卖盘再下单。
  - **补精通（移植上游 v0.8.2–v0.8.5）**：策略里新增“补精通”，按收藏页“即将获得奖励”顺序锁定本轮前六项，每项只补下一档，刷新后继续；跳过传说品质与种植任务，只认亲自产出的收藏计数。缺同品质材料时继续采集、偷窃或打怪等待产出（市场询价同时进行），攒齐后按该品质配方制作，不占用计划装备的品质材料。粗糙宝石等副产物按精确品质、掉率、成功率与往返耗时比较全部已解锁来源（例如宝石摊对比铁矿）。
  - **游戏引擎模拟**：从公开客户端自动提取游戏自身的逐刻模拟引擎（不依赖混淆后的名称，带纯净性与自检），在后台 Worker 中按真实角色状态模拟每个怪物与已解锁工作一小时，用于全部策略的经验／金币排序；实际测得的速率仍优先，模拟阵亡的路线视为不可行，任何失败都退回公式估算并在数据状态中说明。
  - **每日任务必做**：取消 20 分钟上限与经营模式收益门槛，任何刷新前能完成的每日都会做，最快的先做，指定主业也不例外；热门时段只在不紧急时推迟。每日原料链加入市场比价，自给需要长时间解锁时（如没有伐木等级却要做鱼竿）改为直接买便宜原料。
  - **任务面板**：每天唯一一次免费重抽只用于无法完成且未开始的每日。被服务器拒绝时 6 小时内不再尝试，不暂停助手；玩家自己操作这些不算接管。

  - **装备档位说明**：当前装备显示品质与强化等级；“当前可穿”按现有等级找升级：每款取能胜过当前装备的最低品质（例如史诗钢剑时推荐稀有钴剑，近战 60 可穿），材料按该品质配方计算，并沿品质链核对库存（例如罕见钴矿 → 罕见钴锭 → 罕见钴头盔），材料名带品质，缺的品质原料单独列出；“下一档”是下一个穿戴等级的升级；“缺料”拆为制作本身所需和练级至解锁及供料链所需（后者通常大得多），数字带千位分隔。

  - **精通点数按实际时间占比分配，并攒点**：以前只模拟当前目标的工作（制作目标时制作速度显得最好），且总在买得起的里面挑。现在按实测的时间分布（采集、制作、战斗的工作时间和走路时间）算每一级省下的总时间：经验获取作用于全部时间，采集速度只作用于采集，制作速度只作用于制作，移动速度作用于走路，战斗三项按引擎模拟；只买每点省时最多的一项，买不起就攒点，不退而求其次。计划页显示分配或攒点对象。
  - **世界 Boss 倒计时不再让后台规划作废**：有 Boss 即将出现时，倒计时每秒变化，被当作“状态已变”，后台算好的结果连续作废，只能每三次改在页面内算一次（诊断里的“因‘世界 Boss’变化作废”）。规划只关心 Boss 是否在 5 分钟内出现，现在只比较这一点。
  - **疾行药剂按整条路线的走路占比计价**：以前只在“接下来 10 分钟内有新路程”时才考虑疾行药剂（制作、背包十分钟内装不满的采集都不考虑；助手自己的无限路线也被跳过），所以诊断里只看到其他药水。药水按约 20 小时连续保持，现在按本任务的走路时间占比计价：有实测（引擎模拟或实际运行）用实测，否则按每装一背包的存仓往返估算；占比 2% 以上即列入补药与饮用。
  - **买成品还是买原料自制，一律比较**：任何要买的东西（材料、种子、物品目标、食物、药水）在直接买之前，先估算“买原料自己做”的成本：库存原料按可卖价、缺的原料按卖盘价，加上制作时间 × 金币收益；当前目标正是该制作技能时，自制经验省下的练级时间全额抵扣。因为自制有经验，只要自制不超过直接买价的 1.15 倍就自制（缺的原料再按同样规则决定买还是自采）。装备升级原本就和自制方案比较，未改。
  - **药水真正会补了（疾行药剂等）**：以前采购上限是“基础估值 × 3”（疾行药剂只肯付 288，市场约 1,980），所以从来买不到；现在按“金币换时间”：一瓶的药效一小时能省下的时间 × 当前金币收益（疾行按本路线的路程，经验药水按 +10% 经验，战斗药水按缩短的战斗时间），回本 1.2 倍以上才买，未知收益的药水仍用旧上限。顺路补药也覆盖助手自己的无限路线（之前只在有次数上限的路线返仓时才补）。缺药时比较两种来源的每瓶成本：直接买药水（卖盘价），或自制——库存原料按其可卖价计、缺的原料按卖盘价计，加上炼药和往返时间 × 金币收益；当前目标是炼药时，扣除自制经验省下的练级时间。取较便宜者：自制更便宜时先用库存原料做（换任务或返仓时开做，做完继续原任务），缺原料则返仓时买原料再做；否则买药水。
  - **采集收益计入全部品质和额外掉落**：采集的金币/时以前只算普通品质产出；现在罕见、稀有、史诗、传说产出和额外掉落（如粗宝石）都按市场价值计入（最新买单，无买单按商人价，税后），战斗的品质掉落同样计入。品质概率按游戏规则（一次掷骰同时决定各品质，工具和护符幸运相乘）；游戏引擎模拟可用时，从模拟中实测总倍率（含药剂、房屋、精通等加成），明显高于工具＋护符时改用实测值。这些品质产出只计价值、不出售：传说物品（含传说矿石）照旧保留。
  - **完成当前批次时仍显示备料进度**：等当前采集背包满或批次完成时，状态不再只显示“继续当前采集…”，后面接上“之后：备料 钴锭 ×N：钴矿 a/b、煤 c/d”（按实时库存），或上次规划给出的下一步说明；刚接手、尚未到任务边界的目标会先预览一次下一步（不改动目标本身）。面板标题的版本号后显示构建时间（如 `v0.8.0 · 10-15 20:32`），便于确认已装上新版本。
  - **任务等作物时不再整小时空闲**：必做的每日／每周任务需要的草药还在生长时（例如炼药任务等夜影草成熟），该任务暂缓到作物成熟，期间先做其他工作；之前同一任务会在每次尝试中被重新选中，所有候选都被判为“等待”，角色一直空闲。控制台可运行 `deepveinDebug()` 查看助手当前在等什么，以及最近几次后台规划的结果。
  - **修复长时间空闲**：世界 Boss 因食物跳过时，状态文字每秒追加一次，导致每次后台规划结果都被当作过期而丢弃，角色一直空闲且没有日志。状态文字不再参与过期判断，也不会重复追加；后台结果连续 3 次作废时，诊断页会写明是哪部分状态在变化，并改在页面内直接算出下一步。
  - **停靠面板只有一个滚动条**：停靠在游戏侧栏时，外层不再出现白色滚动条，由内层深色内容区滚动（状态栏和标签页固定在上方）。
  - **金币收益扣除自有材料价值**：估算工作的金币/时时，用到仓库已有材料按其可卖价（市场、回购、商人中最高）扣除；购买的材料本来就按买价扣除；自己采集的材料只计时间。仅影响金币估算，不影响经验估算与采购预算。
  - **先打造计划装备，品质材料留给装备**：每个位置计划的装备（当前可穿的升级和下一档）取现有材料能做出的最高品质（最多史诗，按材料而不是当前制作等级判断；材料按武器、护甲、饰品、工具的顺序依次分配，不重复计算）；材料不够任何品质时，装备卡仍显示能胜过当前装备的最低品质作为目标。这些计划装备所需的品质材料（已有的品质锭，以及还没做成锭部分的品质矿石）在练级时保留，不会被做成锭或板刷经验；现在就能用库存做出、且制作等级够的计划装备（不限制作技能，例如制作阶段也会打造锻造的钴工具和护甲）在练级前先做出来：先一次把它们共需的品质中间材料（如全部罕见钴锭）炼好，再逐件打造并穿上。
  - **发展计划整段备料**：自主发展的制作计划先把到目标等级（本阶段）所需的全部材料备齐再开始制作，不再按一级一级“采一点、做一点”；判断方法只有一个总数：按普通品质经验算出本阶段需要的制作次数，把各品质现有材料能做的次数加起来（同一配方的输入须同品质配对，例如罕见青铜锭要罕见铜矿加罕见锡矿；煤炭等普通输入共用），总数够了就一定能练到目标，于是开始制作，高品质先做（每次经验更高）；不够就采集普通材料补足差额，途中掉落的品质材料也立即计入总数；备料期间任何技能经验都算进展，不会被判为停滞。主业经营与固定工作仍按原批次。
  - **金币换时间（投资规则）**：强化、买装备和房屋点数用同一条回本规则：花费按金币最高工作的收入折成小时，收益按装备使用期内（到下一档或最多一周）同样进度省下的时间算，省下超过花费 1.2 倍才做。强化成本是期望值，含失败归零后重来（例如普通钴装备到 +5 约 7.3 万金币，稀有钴约 58 万），并自动选最省的停止点（不一定是 +5）。同一位置比较“强化 / 换更高品质 / 换其他装备”，只做最省的一项。值得但钱不够时，先做金币最高的工作筹资，最多 1 小时，未筹够则该项暂缓 6 小时。计划页新增“投资”列表，显示花费、赚钱时间、省下时间和结论。取代原来“+1 先强化、之后只用盈余和 25% 碎片”的规则。
  - **自主发展改为均衡范围**：所有技能保持在最低技能以上 10 级以内（每 10 级所需经验约为前 10 级的 3 倍，低等级最便宜），领先的技能等其他技能追上；范围内按速度、其他技能用得上的解锁和收入选择；所选技能下一档配方的原料技能（例如锻造所需矿石的采矿）尚未达到所需等级时，先练原料技能；需要怪物掉落时（例如炼药的怨灵之尘），按规划器的安全判断算出能安全刷该怪物的最低战斗等级，战斗不够就先练战斗。
  - **计划页比较方式**：自主发展与主业经营只在当前目标技能内比较经验（各技能经验与等级表不同）；经验优先比较全部技能的经验；金币始终按全部技能比较。
  - **普通煤炭从不出售**：所有品质的冶炼都用普通煤炭，出售、满仓清理、原地丢弃和房屋转换都不会动它；更高品质的煤炭可作房屋点数材料。
  - **房屋点数按每点最低售价选料**：按游戏规则计算点数（原料按档位，制作品按原料点数和制作深度最多 ×2，每升一档品质 ×3，强化物品不能转换），每种材料按三层出售（市场、城镇回购、商人）中最高售价折算每点金币，先用最便宜的；包括罕见至史诗品质材料和多余制作品，保留传说、计划所需材料、口粮、已穿或套装装备、仓库锁定物品和普通煤炭。
  - **农田不空闲**：作物库存都已充足时不再搁置成熟作物，在任务结束、返仓或空闲时收获并用现有种子续种，农业经验最高的优先；不为此买种或采种，正在进行的任务不被打断。
  - **停滞路线**：制作／采集路线停在原地没有进展时 30 秒内发现并重启；重启后仍停滞则暂缓该目标 10 分钟改做其他工作，不再反复空等。

## 安装一次，后续检查更新

先安装 Tampermonkey，再打开上方安装链接并确认安装。原来通过本地文件安装的用户也需从此链接更新一次，以保存固定更新地址。保留一份助手和一个游戏标签页。

在 Tampermonkey 中启用该脚本的更新检查与自动安装更新。作者发布更高版本后，各设备按照自己的设置检查更新；更新完成后刷新游戏，新代码才会运行。各设备首次安装一次即可，游戏角色与脚本运行配置不会通过此仓库同步。

助手也会在打开页面时及之后每小时检查一次公开版本，发现新版会在标题旁显示更新入口，面板收起仍可见。底部“检查更新”可手动检查（每分钟最多一次）；失败不会停挂机。点击“安装／更新”由油猴处理，完成后刷新游戏。提示比较当前页面运行版本，即使油猴已下载新版，旧页面也要刷新才能生效。仅无凭据读取固定 GitHub 公开元数据，不上传角色信息，不执行远程元数据，不强制刷新或打断任务。

没有安装提示时，在 Tampermonkey 的“从 URL 安装”入口粘贴上方安装链接。

## 使用范围

这是有限时间内的收益规划，不承诺全局最优或真实账号连续运行 24 小时。补齐装备前置技能可能花较长时间，优先完成这一明确目标不等于任何装备立即升级都能取得最高经验或最快回本。药水补购的基础价值上限不等于保证市场便宜；缺货、报价过高或预算不足时会继续工作，不能保证药效永不间断。电脑休眠、关闭页面、服务器维护或登录失效会中断运行。请遵守游戏的自动化规则。

市场报价缺失时保留物品、继续练级并稍后重试；价格及成交量会变化，不能保证挂单成交。交易结果不明时保留记录、同步核实，不重复下单。留货按当前计划及周转储备计算，不保证覆盖未规划的公会、住房或未来切职业需求。公会捐赠、Town 交货及任务点加点尚未自动执行。阶段成长会牺牲部分总经验，供料和后台农业仍可能让个别技能领先，不保证等级完全相同。

本仓库只分发完整脚本、更新元数据与安装说明。脚本内置的 Acorn 保留其 MIT 许可声明。

## 开发

源码位于 `src/`（ES 模块），发布文件由 esbuild 生成，请勿直接修改根目录的 `*.user.js` / `*.meta.js`：

```
npm install
npm run build
```

- `src/main/entry.js`：页面脚本入口；`src/worker/entry.js`：后台规划 Worker 入口（构建后以字符串内嵌）。
- `src/planner/`、`src/economy/`、`src/runtime/`、`src/ui/`：规划、市场、运行时与界面模块；`src/data/game-data.json`：内置游戏数据。
- 共享规则只写一处，新功能直接引用，不要另写一份：`planner/items.js`（物品 id、名称、库存、背包、地图、价格与时间换算）、`planner/levels.js`（等级与经验）、`planner/quality.js`（品质规则与各品质概率）、`planner/keys.js`（测量记录的键与可信样本）、`planner/result.js`（决策结果格式）、`planner/gold.js`（金币折算时间、回本、最高可付价）；金币效率用 `planner.coinRate`／`planner.goldJobs`，出售价值用 `planner.saleValue`，市场报价用 `market.js` 的 `topOfBook`。
- 版本号取自 `package.json`；GitHub 与 Gcore CDN 两个发布版本只在更新地址和 `SCRIPT_DISTRIBUTION` 上不同。
- 后续计划见 [docs/roadmap.md](docs/roadmap.md)。
